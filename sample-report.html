1. Executive summary

The GW-200 has a good base but four gaps that would block CRA conformity, and one issue that matters today under the reporting obligation in force since 11 Sep 2026:

  1. Outdated Mbed TLS 2.16.0 (end of life) is linked into the image, with 38 known vulnerabilities.
  2. Firmware updates are not cryptographically signed.
  3. The debug port is open on production units.
  4. Every unit ships with the same web-UI password.
  5. No one is assigned to CRA vulnerability reporting.

3. Findings

F-01 · End-of-life Mbed TLS 2.16.0 with known vulnerabilities Critical

CRA: Annex I Part I (2)(a), no known exploitable vulnerabilities; Part II (1)

Evidence: mbedtls/version.h → 2.16.0; ssl_tls.o, x509_crt.o, bignum.o present in the linker map. The 2.16 branch has been end of life since 2021. 38 matches, including CVE-2021-44732 (Critical; fixed in 2.16.12 / 2.28.0). The TLS client handles every cloud connection, so it is reachable from the network.

Recommendation: Upgrade to Mbed TLS 3.6 LTS. The 2.x to 3.x API changes are concentrated in the TLS client configuration (about 300 lines). Regenerate the SBOM and rescan.
